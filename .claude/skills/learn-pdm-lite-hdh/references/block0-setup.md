```
예지보전 실습판 준비를 해 줘.
1. 내 홈 폴더에 kma-pdm-lite 폴더를 만들고, 그 안에 data 폴더를 만들어
   {SKILL_DIR}/assets/lab/Day5_설비센서_50건_가상.csv 를 복사해 줘.
   원본 파일은 고치지 마.
2. Python과 git이 있는지 확인해 줘. 없으면 설치해 줘.
3. csv의 행 수, 열 이름, 설비 이름, 시간 범위, 단위를 보여 줘.
4. 결과를 kma-pdm-lite/env_check.txt 에 OK / 조치 필요로 적어 줘.
```

- `data/Day5_설비센서_50건_가상.csv`가 50행, 설비A·설비B 각 25행
- 열: 시간 · 설비 · 진동(mm/s) · 온도(℃) · 압력(bar) · 비고
- Python·git이 OK
